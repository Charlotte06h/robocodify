# 开发实验索引

[results.json](results.json) 是选定开发批次的机器可读摘要，保留全部已完成 episode、
原生成功/score、Agent 自评、步数和耗时，不按结果挑选样本。
[configs.json](configs.json) 记录对应模型、预算、依赖和模块/附录哈希。
[artifacts.json](artifacts.json) 记录来源文件的相对档案标识与 SHA-256。

这里不是完整历史数据集。原始 `research-evidence/` 仍由项目所有者保管，
没有公共下载链接；索引中的相对路径不是本仓库内可点击的文件。
结果来源 `analysis.json` 为离线汇总，原生明细字段与 Agent 判断分别提取。

## 结果范围

- 2026-11-16 tower 随机 10 局：2/10 成功，平均 score 22；没有同期原版对照。
- 同日充电器续跑：7 局完整，0/7 成功；第 8 局由用户中止，未混入完整局分母。
  原计划余下任务未启动，先前环境启动失败也另留档案，不能视为策略 episode。
- 2026-11-17 当前版本四个单局：tower、充电器、挂杯子、插笔筒。
  四局原生均失败；挂杯子 score 40、插笔筒 score 25；单局不代表任务成功率。
- 以上批次有不同模块/提示词版本，不能合并估计当前方法的成功率。

此前按钮、钥匙、关键帧等实验仍在外部档案；本次未重新汇总成一张总表。
完整原实现记录的来源哈希在根目录 `provenance.json` 中。
旧输入与环境适配限制见 [复现约定](../docs/reproduction.md)。
